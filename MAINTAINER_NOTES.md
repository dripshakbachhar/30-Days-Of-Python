# Repository provenance and learning record

This repository contains the **30 Days of Python** learning challenge by **Asabeneh Yetayeh** (second edition, July 2021), as credited in the lesson material. The lessons are educational source material; their presence here does not mean I authored the curriculum.

## How to use this repository

- Start with [readme.md](./readme.md), then follow its Day 1–30 table in order.
- Each day folder contains the lesson for that topic. Follow the links in the lesson to move between days.
- Read and run small examples in a local Python 3 environment. For a standalone example file, run `python path/to/example.py` (on systems where the command is `python3`, use that instead).
- Some lessons discuss optional third-party packages, web services, databases, or network access. Follow the setup instructions for the specific lesson; do not assume every example works without its dependencies or credentials.
- Treat exercises as prompts to solve yourself. Keep personal solutions and reflections clearly labelled separately from the original lesson text.
